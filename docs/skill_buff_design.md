# 技能与 Buff 设计

## 设计范围

- 18 名现有角色、17 种现有怪物，共 35 个单位。
- 沿用现有 140 个技能名称和图标，每个单位固定为普通攻击、主动技能、绝技、被动技能四个槽位。
- 沿用 `assets/buff/texture/status_icons_manifest.json` 中的 12 个增益与 12 个减益图标。
- 数值基于项目现有生命、攻击、防御、速度四项属性，额外战斗属性暴击、命中、闪避均有默认值，不修改角色存档结构。

完整技能数值位于 `assets/script/game/battle/BattleSkillConfig.ts`，状态数值位于 `BattleBuffConfig.ts`。

## 回合规则

1. 回合开始先结算流血等 `turnStart` 状态，再判断眩晕、冰冻、催眠是否跳过行动。
2. 普通攻击不受沉默影响；主动技能和绝技受沉默限制。
3. 回合结束结算中毒、灼烧、持续伤害和持续恢复，然后减少状态剩余回合。
4. 持续伤害不会暴击、闪避、吸血或触发反击，但会被无敌免疫并优先消耗护盾。
5. 控制免疫阻挡眩晕、冰冻、催眠、沉默；坚韧将控制持续时间降低 35%。
6. 催眠受到直接伤害后解除；持续伤害不会唤醒催眠。
7. 同名状态按配置刷新、叠层或替换。中毒最多 3 层、灼烧最多 2 层、流血最多 3 层。
8. 治疗不能超过最大生命；持续伤害可以击败目标。

## 接入顺序

```ts
const engine = new BattleEffectEngine(seedRandom);
const units = [player, monster];

engine.initializeBattle(units);                  // 战斗开始被动
const turn = engine.resolveTurnStart(player.id, units);
if (turn.canAct) {
    engine.executeSkill(skillId, player.id, units, { primaryTargetId: monster.id });
}
engine.resolveTurnEnd(player.id, units);
```

执行器返回的 `BattleLogEntry[]` 用于 UI 飘字、血条变化、Buff 图标、受击和死亡动画。随机数由构造函数注入，因此客户端演示、录像回放和自动化测试可以使用固定种子。
